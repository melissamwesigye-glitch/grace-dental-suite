GRACE DENTAL SUITE — WEBSITE FILES
==================================

This folder is the complete website. It's plain HTML, CSS and images, so it
works on any web host and needs no monthly website-builder subscription.
You own every file.

UPLOAD
------
Upload EVERYTHING in this folder (keep the folder structure) into your
hosting's public folder. On cPanel hosting that folder is called
"public_html". index.html must sit directly inside it.

The hidden file ".htaccess" forces https:// and www, and turns on caching.
It works on Apache/cPanel hosting. On other hosts it's simply ignored.

BEFORE GOING LIVE, CHECK
------------------------
1. Domain: links assume https://www.gracedentalsuite.co.za.
   If the domain is different, it must be updated in every page,
   sitemap.xml and robots.txt (ask whoever built the site to regenerate them).
2. Opening hours (footer, contact page, Google data).
3. That 061 325 0776 is the practice WhatsApp number.
4. The treatment list and medical aids accepted.
5. The three blog articles: read and approve them.

SMALL EDITS
-----------
Each page is a normal .html file. Open it in a text editor
(Notepad / TextEdit / VS Code), change the words between the tags, save and
re-upload that one file. Colours live at the top of assets/css/style.css.

AFTER IT'S LIVE
---------------
Add the site to Google Search Console and submit:
https://www.gracedentalsuite.co.za/sitemap.xml
